# Paper Atlas research workflow

Work in this checkout using uv and a local virtual environment. Read the [preregistration](reports/preregistration.md) and [run matrix](reports/planned-runs.md) before changing any analysis choice. Distinguish preregistered results from exploratory amendments. Use the existing modular collector, inference, geometry, export and reporting stages. Add a regression test when fixing an incorrect result. Store observations under results, full local logs under logs, and scientific reviews under reports. Preserve historical snapshots. Never commit credentials or release request headers. Regenerate numbers and figures with the offline atlas build. Publish the evidence, code and tests before inference, then version each measured release in the GitHub project and the Hugging Face collection.
