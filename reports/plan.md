# Implementation plan

1. Publish the evidence review, protocol and run matrix before inference.
2. Build and push the collector, hosted embedding and naming stages, numerical analysis, tests and static explorer.
3. Collect the all-time paper feed twice, check membership and freeze a dated snapshot.
4. Calculate original-space neighbors, a two-dimensional projection and separate clusters. Record checkpoints and timestamp all API work.
5. Label the clusters with Luna, evaluate all preregistered seeds, and report favorable and unfavorable findings.
6. Regenerate reports and figures, compare exported IDs, inspect the PDF and browser experience, then publish the GitHub Pages site and Hugging Face collection.
