# Pre-inference review · 26 November 2026

**Coverage.** A stable last qualifying rank alone does not establish membership: tied pages can repeat even while scores decrease correctly between strata. Each accepted pass must account for every qualifying rank using distinct group IDs, including the marked external entries subsequently removed. The second pass must produce the same eligible IDs. The source is live, so the two accepted windows and any corroborating alternate vote observations belong with the release. **Evaluation.** The ten-neighbor reference is computed from all archived vectors in float64. Independent two- and ten-dimensional fits separate screen layout from clustering. The PCA and shuffled-position comparisons use the same group IDs and the same original reference. The seed interval measures optimizer variability on this frozen corpus. Interpretation also requires the unassigned fraction, tag coverage and the PCA clustering ablation. [Protocol](../preregistration.md) · [Evaluation implementation](../../../src/atlas/geometry.py)

**Credit ceiling.** The provider client disables implicit retries. Each physical call commits a conservative reservation under a process lock before it is sent. A timeout consumes its reservation even if no receipt arrives. Separate tests exercise simultaneous requests, retry after uncertain delivery, resumption and a user-supplied lower limit. The released monetary estimate must identify the rate card and distinguish missing receipts.
