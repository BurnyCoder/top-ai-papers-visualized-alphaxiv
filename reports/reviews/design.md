# Pre-inference review

The primary outcome compares two projections of identical frozen vectors using a reference constructed independently of the visible coordinates. The display seed and parameters were selected in advance. The noise fraction and jointly assigned sample are required alongside adjusted Rand agreement. Subject metadata remains outside embedding, clustering and labeling. Label evidence is validated against the cluster members present in the prompt.

Authenticated calls run in the command-line pipeline. The static export contains paper metadata, coordinates and derived recommendations. The monitor serves only its dashboard and aggregate progress. SQLite commits completed embedding batches, individual label caches survive interruption, and each seed is checkpointed. Remaining checks are live browser behavior, published membership equality, PDF rendering, and an independent recomputation of selected metrics. [Preregistration](../preregistration.md)
