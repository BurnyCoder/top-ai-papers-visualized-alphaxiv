# Record of the study freeze

The registered analysis and run matrix were pushed before collecting the new corpus. The subsequent release commit contains the canonical compressed census, both independent rank certificates, the preflight token forecast and the code used to validate the published recommendations. The same materials were archived on the dataset Hub before the first charged request. [Registration commit](https://github.com/BurnyCoder/top-ai-papers-visualized-alphaxiv/commit/509b8e8) · [Frozen GitHub revision](https://github.com/BurnyCoder/top-ai-papers-visualized-alphaxiv/commit/7e6efed) · [Frozen Hub revision](https://huggingface.co/datasets/BurnyCoder/alphaxiv-paper-atlas/commit/42ce44fcbb06e628006a456afd1f77d12712e461)

The frozen embedding matrix was archived before fitting UMAP and HDBSCAN. To fit in the available host memory, the numerical implementation transferred already-normalized double-precision vectors to the GPU in row blocks. Each original-space recommendation was independently recomputed on the CPU. The primary projection, PCA baseline and clusters were archived before Luna labeling, and the complete naming evidence and spending ledger were archived before the sensitivity sweep.
